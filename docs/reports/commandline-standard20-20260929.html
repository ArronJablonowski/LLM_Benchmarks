What the suite measures—and what it does not

Coverage

The standard profile contains 20 hand-authored tasks from easy to expert: Linux, macOS, Windows CMD and PowerShell, SSH, distribution administration, nested terminal menus, simulated pfSense and OpenWrt operations, and incident response. A deterministic terminal simulator records exercised commands; a hidden grader checks both workflow and evidence-backed conclusions.

Across all 204 model–harness pairings, the most frequently passed task was pfSense interface recovery (118 clean passes). OpenWrt firewall diagnostics (12) and multi-host incident response (13) were the least frequently passed.

Important qualifications

  • These are local-suite scores, not official vendor or upstream benchmark scores. The pfSense and OpenWrt labs are safe simulations, not live appliance tests.
  • Of 4,080 records, 167 were marked resource_incompatible under the campaign’s fail-forward safety policy. They count as accounted-for observations, not passes.
  • Twelve rows had a grader pass despite an error or timeout run status. This report excludes them from clean-pass totals.
  • Near-perfect check counts can coexist with failed whole-task verdicts; the primary ranking therefore uses whole-task passes.

Methodology and provenance

Counts use unique (model, task_id) pairs from each harness’s *_commandline.jsonl file, with the final row retained if a pair appears more than once. The rank score is the number of rows where status=ok and verdict=pass. Each of the 20 tasks has eight possible checks, for a fixed 160-check tie-break denominator per pairing. Average task time is the mean reported wall_seconds across all 20 observations.
