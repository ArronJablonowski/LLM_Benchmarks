Executive assessment

There is no defensible single “best” pairing across every benchmark. The tasks, model panels, harnesses, and scoring systems differ. The clearest general pattern is that Qwen3.8 27B variants recur at the top of standardized text, cybersecurity, and command-line work, while Muse Glimmer 30B is especially competitive on coding and command-line tasks.

Best pairing by scored suite: Qwen3.8 27B + OpenClaw for standardized text (16/17); Qwen3.8 27B MTP Q8 + Pi for coding (4/9, best check-count tie-break); Qwen3.8 27B MTP BF16 + OpenHands for cybersecurity (13/24); and Qwen3.8 27B + Ollama-direct for command line (19/20). OCR's one-task leaders are all tied on correctness; the table orders successful runs by speed.

Practical choice: For text-heavy and command-line work, start with Qwen3.8 27B on OpenClaw or Ollama-direct respectively. For coding, shortlist Qwen3.8 MTP Q8 + Pi and Muse Glimmer + Pi/Hermes/OpenClaw. For cybersecurity, shortlist Qwen3.8 MTP BF16 + OpenHands and MTP Q8 + Pi. Validate on your own workload before treating a few-point lead as durable.

Method, comparability, and source scope

How the tables were built

  • Read the campaign JSONL result rows on the DGX Spark. The authoritative key is model + task within a harness; for duplicate standard-text retries, the latest observed row was used.
  • Include only pairings with the complete expected task set in each scored top-five table: 17 text, 1 OCR, 9 coding, 24 cybersecurity, or 20 command-line tasks.
  • Define a clean pass as status=ok and verdict=pass. Rank by clean passes, then check count where available, then lower mean task runtime. OCR uses speed to order one-task pass ties.
  • Creative tasks are ungraded; rank those by status=submitted, then time, with a prominent non-quality label.

What not to infer

  • Cross-suite scores are not a common scale. Nineteen of 20 command-line tasks is not equivalent to 13 of 24 cybersecurity tasks.
  • Some harnesses were added in later campaigns with smaller or different model panels. Pooled harness rates are descriptive, not causal estimates of harness quality.
  • One OCR task and six ungraded creative tasks cannot support broad claims about vision or creative quality.
  • Recorded check totals differ in some coding and cybersecurity rows, especially when runs error. Whole-task passes are the primary result.
  • Model tags are treated as distinct variants. No hardware-normalized or power-normalized throughput comparison was attempted.
