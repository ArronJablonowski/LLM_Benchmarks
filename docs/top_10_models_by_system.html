Benchmark coverage

What the models were tested on

The suite checks whether each model can follow exact instructions, reason correctly, write working code, use agent tools, retrieve supplied facts, resist unsafe instructions, and—where supported—read an image.

Current campaigns: 17 core + OCRDirect · Hermes · OpenClawHistorical Studio retained

Suite-specific operational checks Custom controls

Exact Reply smoke test

Confirms the model and runtime can return one required token sequence without commentary or formatting drift.

Simple Reasoning smoke test

Checks a short reasoning chain and exact final-answer compliance before the more specialized tasks.

Coding Micro

Runs a compact Python task through 25 behavioral cases to catch exceptions, unsafe constructs, and boundary errors.

Prompt Injection

Tests whether the model ignores a conflicting instruction and retrieves the authorized fact from the trusted context.

Important scope note: The standardized names above identify the benchmark families and skills represented. This suite uses one compact, deterministic proxy task per family; it does not run the complete official datasets or reproduce official leaderboard scores. The final Spark and Mini campaigns contain 17 core tasks plus OCR in each harness. Unsupported OCR, task errors, timeouts, and content mismatches remain visible and count as non-passes; they are not silently removed from the denominator. The retained Studio results use their historical task coverage.

How the ranking works

Complete paths onlyModels must have a complete observation set for every required local harness on that host. Terminally incomplete, context-overflow, resource-pressure, and OOM paths are excluded.
Latest valid runThe newest complete source is selected for each model and path. When thinking treatments coexist, the most accurate treatment is used and displayed.
Equal path weightingLocal overall accuracy averages Direct, Hermes, and OpenClaw. Optional cloud rankings average their two available agent harnesses, Hermes and OpenClaw. Each current harness has 18 equally weighted tasks, including OCR; skips and execution failures score zero.
Speed is informationalAverage response time and peak recorded temperature are shown for review but never affect rank.
Source: final DGX Spark, Mac Studio, and Mac Mini campaigns completed 2026-08-23. Rankings retain file-level provenance in the accompanying CSV exports and verification manifest.
