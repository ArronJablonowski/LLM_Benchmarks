Suite-specific operational checks Custom controls

Exact Reply smoke test

Confirms the model and runtime can return one required token sequence without commentary or formatting drift.

Simple Reasoning smoke test

Checks a short reasoning chain and exact final-answer compliance before the more specialized tasks.

Coding Micro

Runs a compact Python task through 25 behavioral cases to catch exceptions, unsafe constructs, and boundary errors.

Prompt Injection

Tests whether the model ignores a conflicting instruction and retrieves the authorized fact from the trusted context.

Important scope note: The standardized names above identify the benchmark families and skills represented. This suite uses one compact, deterministic proxy task per family; it does not run the complete official datasets or reproduce official leaderboard scores. Direct, Hermes, and OpenClaw campaigns contain 17 core tasks plus OCR where supported. The Spark DeepSeek Harness campaign contains the same 17 non-image core tasks; OCR is excluded because no verified native image transport was available. Unsupported tasks, task errors, timeouts, and content mismatches remain visible and count as non-passes; they are not silently removed from the denominator. The retained Studio results use their historical task coverage.

How the ranking works

Complete paths onlyModels must have a complete observation set for every required local harness on that host. Terminally incomplete, context-overflow, resource-pressure, and OOM paths are excluded.
Latest valid runThe newest complete source is selected for each model and path. When thinking treatments coexist, the most accurate treatment is used and displayed.
Equal path weightingLocal overall accuracy averages every available required harness for that system: Direct, Hermes, and OpenClaw, plus DeepSeek Harness on the Spark. Optional cloud rankings average Hermes and OpenClaw. The three image-capable paths use 18 tasks; DeepSeek Harness uses the 17-task text-only core. Skips and execution failures score zero.
Speed is informationalAverage response time and peak recorded temperature are shown for review but never affect rank.
Source: DGX Spark, Mac Studio, and Mac Mini campaigns through 2026-08-27, including the completed Spark DeepSeek Harness evaluation. Rankings retain file-level provenance in the accompanying CSV exports and verification manifest.
